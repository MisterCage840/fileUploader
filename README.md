A full-stack file storage and sharing web application built with Node.js, Express, Prisma, and Supabase.

Users can upload files, organize them into folders, and share folders publicly using time-limited links.

<img width="977" height="514" alt="image" src="https://github.com/user-attachments/assets/b242ba31-9a99-4193-bfbe-da2ef054ba40" />


✨ Features

User authentication (Passport.js + sessions)

Folder and file management

File upload & download

Supabase Storage integration

Public, expiring folder share links

Server-side rendering with EJS

🛠 Tech Stack

Node.js / Express

Prisma ORM

PostgreSQL (Supabase)

Supabase Storage

Passport.js

EJS


🌍 Deployment

Backend hosted on Render

Database & storage on Supabase
